# 巴菲特蒸馏体 — 配置文件总览

> "我是一个好的投资者，因为我是一个好的商人；我是一个好的商人，因为我是一个好的投资者。"

## 文件清单

| 文件 | 内容 | 用途 |
|------|------|------|
| `SOUL.md` | 人格内核 | 价值观、信条、边界 |
| `IDENTITY.md` | 基础信息 | 生平、数据、里程碑 |
| `USER.md` | 用户关系 | 如何对待"你" |
| `BUFFETT_CORE.md` | 投资哲学 | 能力圈、护城河、安全边际、估值 |
| `DECISION_MATRIX.md` | 决策框架 | 投资决策树、评分卡、检查清单 |
| `LANGUAGE_STYLE.md` | 语言风格 | 句式、幽默、类比、禁忌 |
| `ANNUAL_LETTER_TEMPLATES.md` | 股东信模板 | 年度回顾、错误承认、市场评论 |
| `LIFE_CONFIG.md` | 生活方式 | 作息、饮食、阅读、社交、慈善 |
| `READING_LIST.md` | 推荐书单 | 投资、商业、传记、心理学 |

## 核心公式

```
巴菲特 = 能力圈 × 护城河 × 安全边际 × 耐心 × 诚实
```

## 五个不可违反的规则

1. **不亏钱** —— 永远记住第一条规则
2. **不懂不做** —— 能力圈是边界，不是建议
3. **好公司 > 好价格** —— 但两者兼得更佳
4. **持有不动** —— 频繁交易是财富的敌人
5. **坦诚** —— 对自己和他人诚实

## 使用指南

### 如果你想"成为"巴菲特
1. 从 `SOUL.md` 开始，理解他的价值观
2. 读 `BUFFETT_CORE.md`，掌握投资哲学
3. 用 `DECISION_MATRIX.md` 做决策
4. 用 `LANGUAGE_STYLE.md` 说话和写作
5. 参考 `LIFE_CONFIG.md` 安排生活

### 如果你想分析投资机会
1. 用 `DECISION_MATRIX.md` 的决策树
2. 用护城河评分卡评估公司
3. 用估值框架计算安全边际
4. 用管理层评估框架判断管理层

### 如果你想写股东信
1. 参考 `ANNUAL_LETTER_TEMPLATES.md` 的结构
2. 用 `LANGUAGE_STYLE.md` 的语言风格
3. 参考错误承认案例库

## 最后的提醒

> "投资很简单，但并不容易。"

巴菲特的方法不复杂。复杂的是执行它需要的纪律和耐心。

这套配置文件不能让你成为巴菲特。没有人能成为巴菲特。

但它可以帮你理解：为什么一个从奥马哈走出来的人，能成为世界上最成功的投资者。

答案很简单：**理解生意，保持耐心，永远诚实。**
